# Результат твоей сборки: разбор лога javac

Ты запустил `build.sh` на Termux — это первая настоящая проверка компилятором.
Лог: **680 ошибок**. Разобрал все.

## Главное

**614 из 680 ошибок (90%) — в одном-единственном файле**, и причина одна:

```
com/roblox/client/personasdk/R.java:7: error: integer number too large
        public static final int inflatedId = 0xffffffff87010000;
```

JADX сгенерировал 64-битный литерал вместо 32-битного. Правильно:
`0x87010000` (без сигнатуры переполнения `0xffffffff`).

**Второе:** `javalang` (мой парсер) пропустил 4 файла, на которых javac
падает. Это доказывает, что проверка компилятором не заменяется статическим
анализом — именно поэтому твой запуск был нужен.

## Что исправлено (78 файлов теперь в `syntax_fixes.zip`)

Новые правила, найденные **только javac**:

| правило | что чинит | файлов | вхождений |
|---|---|---|---|
| **F1** | `0xffffffff87010000` → `0x87010000` (int переполнение) | 1 | **614** |
| **F2** | `public AnonymousClass5(...)` — конструктор с именем анонима → `public void` | 3 | 3 |

Важная деталь F1: первая версия правила изменила **119 файлов** вместо одного.
Причина — JADX пишет внутри `/* */` листинги байткода вида
`r2 = -2147483648(0xffffffff80000000, float:-0.0)`. Это читаемая документация,
а не код. Переписал правило так, чтобы оно работало **только вне комментариев**:
стало 4 файла. Проверено, что `un/s.java`, `SwitchCompat.java` и остальные 115
файлов с байткод-листингами **не тронуты**.

## Что осталось: 66 ошибок в 9 файлах

Это ровно те места, где JADX потерял конструкцию — их не починить механически.

| файл | ошибок | причина | реально? |
|---|---|---|---|
| `qr/e4.java` | 18 | `char` — одновременно тип и поле (`this.char`), каскад | вручную, 1–2 ч |
| `n0/i4.java` | 12 | `static`-блок вложенного интерфейса приклеен к внешнему классу | вручную, 1 ч |
| `Id.java` | 9 | поле `class` + `@Metadata` | вручную |
| `iv/b.java` | 8 | поле `default` + использования в 3 формах | вручную |
| `h0.java` | 7 | то же (`default`) | вручную |
| `p9.java` | 7 | листинг байткода без обёртки в класс | **нет** — полуразобранный dex |
| `fp/m0.java` | 3 | обрыв выражения внутри `throw` | **нет** — тело метода потеряно |
| `pn/a.java` | 1 | enum-константы без объявления enum | **нет** — нужен DEX |
| `AFb1tSDK.java` | 1 | (исправлен F2) | — |

Оценка: **реально чинится 44 из 66** (первые пять строк, 8–10 часов ручной
работы). Остальные 22 — потери декомпиляции, восстановимы только из DEX.
